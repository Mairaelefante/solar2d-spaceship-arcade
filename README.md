# Spaceship Arcade (Solar2D)

A 2D arcade game built with Lua and Solar2D. Pilot a spaceship, collect falling stars, and avoid meteors while keeping track of your score and remaining lives.

## Tech stack
- Lua
- Solar2D (formerly Corona SDK)
- Solar2D physics engine

## Running locally
1. Install the Solar2D Simulator.
2. Open this project folder in Solar2D (the entry point is `main.lua`).
3. Use the simulator to test the game.

## Project structure
- `main.lua`: game entry point and gameplay logic
- `config.lua`: display configuration
- `assets/`: sprites, background, and font
- `main1.lua`: alternate version preserved from development; not the default entry point

## Notes
This is a source-code portfolio project. Gameplay has not been independently tested in this publication environment.
